## Highlights

- Upgrade Tantivy from 0.26.1 to 0.27.0.
- Update the `setup-uv` action used by CI and publishing from 10.1.0 to 10.3.0.

## Breaking Changes

- `CangJieTokenizer` now implements Tantivy 0.27's tokenizer traits. Applications
  using Tantivy 0.26 must upgrade their direct `tantivy` dependency to 0.27 and
  migrate any affected Tantivy APIs before registering this tokenizer.

The `jieba-rs` dependency remains at 0.11.0, and the minimum supported Rust version
remains 1.88. This release does not change cang-jie's tokenization implementation.
